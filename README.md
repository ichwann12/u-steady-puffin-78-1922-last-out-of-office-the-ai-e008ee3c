I have left the office to become a barista. My out-of-office replies are now lattes: warm, brief, and gone in five minutes. Please direct all urgent requests to the espresso machine.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

`main.ts` reads `entry.txt` and writes the entry text to the output directory given by `MAKEFUN_BOT_DIR` or `MAKEFUN_OUTPUT_DIR`. Node 22+, standard library only, no network, no wall clock.
